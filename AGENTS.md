# Orientações do projeto

- Use JavaScript e siga as convenções do App Router do Next.js. Mantenha as rotas em `app/` e o CSS global em `app/globals.css`.
- Consulte `package.json` e `package-lock.json` para as versões das dependências e o `README.md` para os comandos de execução local.
- Ao alterar a aplicação, rode `npm run build` e verifique o comportamento afetado.
